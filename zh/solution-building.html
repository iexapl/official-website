智慧楼宇解决方案

BA · 安防 · 消防 · 能耗 · 访客管理

方案架构

智慧楼宇IBMS架构

智慧楼宇以 IBMS 智能建筑综合管理平台为核心，采用 .NET 8.0 + ASP.NET Core + Furion 微服务架构构建统一数据中台。设备接入层通过 Modbus RTU/TCP、BACnet、OPC UA 多协议网关汇聚楼宇自控（BA）、消防（FA）、安防（SA）、通信（CA）、办公（OA）五大子系统数据；MQTT Broker（EMQX）汇聚 IoT 传感器与边缘网关，RabbitMQ 集群实现跨子系统事件驱动联动，DotNetCore.CAP 保障关键联动指令的分布式事务一致性；Redis Cluster 支撑毫秒级设备状态缓存，SqlSugar 提供 MySQL / MongoDB / 时序数据库多库异构 ORM 能力。数据层以 MySQL 存储结构化业务数据，MongoDB 存储时序监控与告警日志，TDengine 承载能耗与设备运行趋势。应用层以 Vue 3 + Element Plus 打造统一运维管理界面，集成能耗分析、设备预测性维护、租户空间服务与数字孪生可视化；桌面管理端基于 WPF 或 .NET MAUI 构建 Native 级工作站。DevOps 以 Git + Jenkins + NuGet/NPM 持续集成，Docker + Kubernetes 实现本地部署与云端协同的混合模式。

方案组成

楼宇自控系统(BA)
空调、照明、电梯、给排水等设备的自动监控与优化控制。
安防系统
视频监控系统、门禁控制、入侵报警、电子巡更一体化管理。
消防系统
火灾自动报警、消防联动控制、应急广播与疏散指示。
能耗管理系统
分项计量、能效分析、节能控制策略，降低运营成本。
访客管理系统
预约登记、人证核验、电梯联动、访客轨迹跟踪。
智能停车系统
车牌识别、车位引导、反向寻车、无感支付。
