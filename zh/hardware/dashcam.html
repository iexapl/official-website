车载行车记录仪

H6-4G车载行车记录仪，集实时视频、AI分析与北斗/GPS双模定位于一体，适用于物流车队与工程车辆监管。

H6-4G 车载行车记录仪是一款集成了 4G 实时视频传输、AI 智能分析、北斗/GPS 双模定位的高性能车载终端。采用 200 万像素传感器，支持 1080P 高清录像、H.265 视频压缩、红外夜视与智能白光，可实现实时位置追踪、视频直播、驾驶行为分析与紧急事件自动上报。

4G 实时传输

LTE Cat.1 通信，支持实时视频上传、轨迹回放与远程监控。

AI 智能分析

人体探测、异常行为识别，停车监控时自动触发告警。

双模定位

GPS + 北斗双模，64 通道，定位精度 <2m，支持 AGPS 辅助定位。

高清夜视

红外夜视 + 智能白光，夜间行车与停车监控画面清晰。

大容量存储

TF 卡最大支持 512GB，H.265 压缩节省存储空间。

型号选型

车载视频终端按功能用途组织类别，四类功能可在同一台终端上组合实现。

车载视频终端

  • 前向与舱内风险预警

行驶记录与数据留存

  • 本地存储、断电保护与回放取证
  • 本地留存与事后取证

定位与远程视频监控

  • 定位、地理防护与车队远程调阅
  • 车队远程调阅与区域管控

接口兼容

4G 网络

  • LTE FDD/TDD 全频段，支持实时视频流、数据上传与远程指令下发。

RS485

  • 可接入油耗传感器、载重传感器、温湿度传感器等车载外设。

平台对接

  • 支持 AXLTeco 车辆管理平台、国标 GB/T 32960 平台对接。

API 接口

  • 提供位置查询、视频调阅、告警订阅、轨迹回放等 REST API。
