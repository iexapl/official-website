Attendance Devices

Facial Recognition · Fingerprint · Card · Mobile

AXLTeco provides multiple attendance terminal devices to meet the clock-in needs of different enterprises and scenarios.

Caractéristiques Clés

Facial Recognition
No-contact clock-in, 0.3s recognition, supporting mask detection and liveness detection.
Fingerprint
Optical / capacitive fingerprint modules, large-capacity storage, supporting dry/wet finger recognition.
IC Card
Support M1, CPU card and ID card, with anti-passback and multi-card functions.
Mobile Clock-In
GPS + WiFi + Bluetooth multi-mode positioning, support off-site and field clock-in.
Cloud & Local
Support cloud-based and local deployment, with data synchronisation.
Intégration API
Open API for integration with HR systems and payroll systems.

System Advantages

Suitable for offices, factories, construction sites and schools. Support multi-branch unified management and real-time data synchronisation.
