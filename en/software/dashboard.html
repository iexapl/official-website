Dashboard System

Aggregates multi-source business data into intuitive visual charts, supporting real-time monitoring, flexible customisation and multi-terminal display.

Enterprises generate vast amounts of dispersed data during daily operations, and traditional reports struggle to present key metrics and business trends in real time. The Dashboard System integrates multiple data sources, provides rich chart displays, real-time refresh and drag-and-drop layouts to transform complex data into intuitive management views, supporting command centre and other scenarios to help enterprises achieve data-driven decision making, improve operational transparency and response speed.

Key Features

Data Integration

Unify and aggregate seven types of heterogeneous data sources—databases, APIs, Excel/CSV, IoT, ERP, MES and WMS—through standardised connectors, breaking data silos and achieving one-stop data integration.

Rich Charts

Built-in chart-rendering and map engines support line charts, bar charts, pie charts, gauges, geographic heatmaps and more, meeting diverse visualisation needs across business scenarios.

Real-Time Refresh

Powered by the SignalR real-time push engine, data changes are instantly refreshed on the dashboard, combined with scheduled refresh to ensure management always has the latest business insights.

Drag-and-Drop Layout

The no-code drag-and-drop layout engine lets users freely adjust chart positions, sizes and layering, enabling rapid creation of personalised dashboards without development, lowering the barrier to use.

Permission Control

Dual fine-grained permission control at both page and data levels ensures different roles can only view authorised metrics and reports, safeguarding enterprise data security.

Multi-Terminal Display

The large-screen adapter engine automatically adapts to command centres, PCs, tablets and mobile phones, supporting multi-screen linkage and responsive display, covering all scenarios from command centres to mobile offices.

Application Scenarios

Command Centre Data Wall

Large-screen visualisation dashboards are deployed in conference rooms or command centres, aggregating multi-source business data from ERP, MES, WMS and more in real time, helping management quickly grasp the overall situation and make precise decisions.
