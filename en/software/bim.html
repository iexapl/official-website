BIM Lightweight System

Lightweight large BIM models for smooth Web and mobile browsing and review.

The BIM Lightweight System is a collaborative review platform that makes large BIM models smooth to browse on Web and mobile. Addressing the pain points of slow loading and laggy browsing caused by bulky native BIM files, the system delivers model compression conversion, smooth Web browsing, multi-device collaborative review, model comparison, and property query, allowing bulky 3D models to run efficiently across all devices, helping teams achieve cross-region collaborative design and on-site precision verification.

Key Features

The system covers six core modules: model lightweight, Web browsing, multi-device collaboration, model comparison, property query, and section measurement.

Model Lightweight

Intelligent compression and geometric optimisation algorithms automatically process Revit, Bentley and other native models, reducing file size by over 80%.

Web Browsing

WebGL rendering engine — no plugins required.

Multi-Device Collaboration

Synchronised viewing and annotation across PC, tablet, and mobile.

Model Comparison

Automatic comparison of model versions with highlighted design changes.

Property Query

Click any component to view complete engineering properties.

Section Measurement

Arbitrary-angle section, distance, area, and volume measurement.

Advantages & Guarantee

Core Advantages

Multi-format Compatibility

Supports importing mainstream BIM software formats including Revit, Bentley, and SketchUp, with extensive model format compatibility to protect existing design assets.

Cloud-based Lightweight Processing

Models are automatically processed via a lightweight processing pipeline and stored on the cloud, enabling zero-latency global access and efficient, smooth cross-regional multi-party collaboration.

Plugin-free Browsing

Based on the WebGL rendering engine, viewing and interaction can be performed directly on the web without installing any plugins, greatly lowering the threshold for use.

Microservices Architecture

The underlying layer is built on the .NET 8.0+ microservices platform. Each service is deployed independently and elastically scalable, facilitating subsequent feature iteration and system maintenance.

Multi-terminal Collaboration

Supports access via multiple terminals including PC Web, mobile devices, and large-screen dashboards. Design, construction, and supervision parties can share the same model view in real time.

Version Traceability

Version history is automatically recorded when a model is uploaded, supporting rollback and comparison of any historical version, making change management clear and controllable.

Delivery Services

Requirement Research

Gain in-depth understanding of the collaboration requirements, current model format status, and network environment of the design team and construction party, and develop a personalized implementation plan.

System Deployment

Supports flexible deployment on private or public clouds, adapting to project requirements with different security levels and network conditions.

Training and Launch

Provides tiered training for administrators and end users, covering model upload, lightweight processing, permission configuration, and daily operations.

Service Guarantee

Continuous Operation and Maintenance

7×24 hour remote technical support, regular system inspections and feature iterations to ensure long-term stable operation of the platform.

Data Security

Model data is stored encrypted, with hierarchical permission control and full recording of operation logs, supporting compliance audits and traceability.

Upgrade and Expansion

Supports smooth upgrade according to project phases, and new feature modules can be launched independently without affecting existing business operations.
