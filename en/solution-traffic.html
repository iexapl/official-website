Solution Architecture

Intelligent Traffic Management Architecture

The Intelligent Traffic Management adopts a three-tier Front-End Perception - Edge Computing - Central Analysis architecture. The front end deploys video detectors, radar, signal controllers and AI edge boxes for real-time recognition of traffic volume, violations and road incidents. The edge layer completes signal optimisation and area coordination control through local compute nodes, reducing central platform load. The central platform is built on .NET 8.0 + ASP.NET Core + Furion microservices, with DotNetCore.CAP guaranteeing transactional consistency for signal control and violation penalties, RabbitMQ clusters aggregating roadside multi-source events, Redis Cluster caching real-time road conditions and signal states, MySQL storing traffic facility archives, MongoDB storing video evidence and traffic time-series data, and SqlSugar providing multi-source ORM mapping. The application layer builds a traffic command dashboard with Vue 3 + Element Plus, integrating six subsystems: signal control, video patrol, violation detection, flow analysis, guidance publishing and bus priority; desktop command clients are built on WPF or .NET MAUI. DevOps uses Git + Jenkins + NuGet/NPM for CI/CD, with Docker + Kubernetes for elastic deployment.

Solution Advantages

The system is compatible with multiple mainstream signal controller brands at home and abroad, protecting existing investments. AI video analysis technology eliminates the need for destructive road surface coil installation, with short construction cycles and low maintenance costs. Open data interfaces support integration with city traffic command centers and map service providers.

Solution Value

Improve road capacity, reduce traffic accidents, optimize public transit services, and provide data support and decision-making basis for urban traffic management.
