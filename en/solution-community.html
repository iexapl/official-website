Smart Community Solution

Access · Parking · CCTV System · Property · Services

AXLTeco smart community solution uses IoT and information technology to provide residents with safe, convenient and comfortable community living.

Solution Architecture

The Smart Community adopts a Cloud-Edge-Device collaborative architecture. The cloud layer builds a community digital middle-platform on .NET 8.0 + ASP.NET Core + Furion microservices, with DotNetCore.CAP supporting distributed transactions across business domains, RabbitMQ clusters orchestrating business event flows for security, access, property and lifestyle services, MySQL storing resident profiles and work-order data, MongoDB storing video surveillance metadata and behavioural logs, and Redis Cluster supporting high-frequency caching for access authorisation and parking billing; SqlSugar provides multi-source ORM capabilities. The edge layer deploys local MQTT Broker gateways and lightweight service nodes for offline buffering and local linkage; the device layer covers face-recognition access control, licence-plate recognition barriers and smart sensors, connecting via MQTT / CoAP / HTTP. The resident side develops a cross-platform app with uni-app x (Vapor Mode), the property side builds an operations management back-office with Vue 3 + Element Plus, and desktop management clients are built on WPF or .NET MAUI . DevOps uses Git + Jenkins + NuGet/NPM for CI/CD, with Docker + Kubernetes for elastic deployment.

Solution Components

Smart Access
Face recognition, card, PIN and remote entry with visitor QR code passes.
Smart Parking
ANPR, parking guidance, cashless payment and automatic monthly renewal.
CCTV System
Full community coverage with high-altitude falling object detection and face recognition.
Smart Property
Online repair requests, fee payment, notices and complaint handling.
Convenience Services
Parcel lockers, EV charging, smart waste sorting and community marketplace.
Elderly Care
Abnormal behaviour monitoring for seniors, SOS emergency calls and health records.

Application Scenarios

Applicable to residential communities, apartments, villas and care homes. Provides safe and convenient access, efficient property services and rich lifestyle services.

Solution Advantages

Unified platform integrating multiple subsystems; face recognition for seamless access; ANPR cashless parking; AI video analytics for proactive safety; online property services improving efficiency and transparency.

Solution Value

Improve community safety and property service efficiency, enhance resident convenience and satisfaction, and increase property values. Data-driven operations reduce costs and create better living experiences.

Project Practice

Delivered smart community solutions for multiple residential projects covering access control, parking, CCTV System and property services, significantly improving management efficiency and resident satisfaction.
