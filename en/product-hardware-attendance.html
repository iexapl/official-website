Attendance Devices

Facial Recognition · Fingerprint · Card · Mobile

AXLTeco provides multiple attendance terminal devices to meet the clock-in needs of different enterprises and scenarios.

Key Features

Facial Recognition
No-contact clock-in, 0.3s recognition, supporting mask detection and liveness detection.
Fingerprint
Optical / capacitive fingerprint modules, large-capacity storage, supporting dry/wet finger recognition.
IC Card
Support M1, CPU card and ID card, with anti-passback and multi-card functions.
Mobile Clock-In
GPS + WiFi + Bluetooth multi-mode positioning, support off-site and field clock-in.
Cloud & Local
Support cloud-based and local deployment, with data synchronisation.
API Integration
Open API for integration with HR systems and payroll systems.

Product Series

Face Recognition Terminal
Liveness detection anti-spoofing, 0.3s fast recognition, supporting mask detection, real-time attendance upload.
Fingerprint Terminal
High-precision optical/semiconductor fingerprint recognition, supporting dry/wet fingers, large-capacity storage.
Card Terminal
IC/ID card clock-in, supporting access control linkage, suitable for factories and large parks.
Mobile Terminal
GPS positioning + WiFi clock-in, field staff attendance management, trajectory recording.

Application Scenarios

Suitable for offices, factories, construction sites and schools. Support multi-branch unified management and real-time data synchronisation.

System Advantages

Attendance devices seamlessly integrate with HR management systems, with automatic attendance data synchronisation, supporting complex shift scheduling, leave approval, overtime statistics and automatic attendance report generation. Devices support Chinese and English interfaces, adapted to local African usage environments.
