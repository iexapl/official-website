Pedestrian Access

Speed · Safety · Smart · Durable

AXLTeco provides various pedestrian access control devices, including turnstiles, speed gates and flap barriers, for buildings, stations and industrial parks.

Key Features

Face Recognition Access

Frictionless access, fast recognition, supporting liveness detection.

Card Access

Support IC card, ID card and CPU card access.

QR Code Access

Support mobile QR code scanning for access and visitor authorisation.

Visitor Management

Support visitor appointment, temporary authorisation and entry/exit records.

Access Records

Automatically record all access events, supporting query and reporting.
