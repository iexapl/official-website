Smart Parking Solution

LPR · Guidance · Car Finder · Automated Payment

Solution Architecture

The Smart Parking solution adopts a three-tier Device-Edge-Cloud architecture. The device layer deploys licence-plate recognition cameras, parking-space magnetic/video detectors and barrier controllers, with edge gateways enabling local billing decisions and offline autonomy. The cloud platform is built on .NET 8.0 + ASP.NET Core + Furion microservices, with core services including vehicle recognition (supporting multiple national plate formats), parking-space management (Redis Cluster real-time status sync), billing settlement (RabbitMQ asynchronous transaction reconciliation, with DotNetCore.CAP ensuring financial transactional consistency) and operations reporting (MongoDB multi-dimensional analytics). The data layer uses MySQL for member and transaction data, MongoDB for entry/exit records and video evidence, with SqlSugar completing multi-source ORM mapping. The management side builds an operations back-office with Vue 3 + Element Plus, the driver side develops a cross-platform mini-program with uni-app x (Vapor Mode), and the attendant side has a cross-platform native APP built on .NET MAUI, with tri-terminal data synchronised in real time via message queues to ensure stable operation under high concurrency. DevOps uses Git + Jenkins + NuGet/NPM for continuous delivery, with Docker + Kubernetes for elastic deployment.

Solution Components

License Plate Recognition
HD cameras with >99% recognition rate, supporting multiple plate formats.
Parking Guidance
Ultrasonic/video detectors monitor space status in real time, with guidance screens directing drivers to available spots.
Reverse Vehicle Finding
Drivers enter their plate number to locate their vehicle and get navigation to the parking spot.
Unattended Payment
Automatic billing, QR code payment, and contactless payment eliminate the need for manned exits.

Commercial Complexes

Multi-level parking management for shopping malls and office clusters, supporting peak-hour tidal lane scheduling.

Residential Communities

Automatic entry for residents, visitor pre-registration, flexible monthly/temporary parking billing.

Transportation Hubs

Long-term parking management and quick vehicle locating for airports and railway stations.

Smart retrofitting of urban roadside parking spaces with dual-mode detection and electronic payment.

Solution Advantages

The system supports both cloud management and local deployment, flexibly configurable according to parking facility scale. Integration with building management and fire systems enables intelligent parking as part of a unified smart building ecosystem.
