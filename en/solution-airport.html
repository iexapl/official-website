Smart Airport Solution

Security · Operations · Passenger · Baggage · Energy

Solution Architecture

The Smart Airport solution adopts an Edge-Gateway-Cloud collaborative architecture. The edge layer covers IoT sensing devices and edge gateways across terminals, aprons, and cargo zones, acquiring local data via MQTT over TLS and OPC UA with on-site preprocessing. The platform layer builds a data middle-platform on .NET 8.0 + ASP.NET Core + Furion microservices, with DotNetCore.CAP supporting distributed event-bus and eventual-consistency transactions, RabbitMQ clusters orchestrating asynchronous event-driven communication across six subsystems (security, boarding, baggage, FIDS, surveillance, and BMS), Redis Cluster caching hot flight dynamics and passenger trajectories, and SqlSugar providing multi-source ORM mapping. The data layer uses MySQL for structured business data and MongoDB for logs and unstructured video evidence. The application layer builds an airport operations command dashboard and management back-office with Vue 3 + Element Plus, and develops passenger mobile services with uni-app x (Vapor Mode) for flight push notifications, smart navigation and paperless travel; desktop management clients are built on WPF or .NET MAUI (WinUI 3 underpinning). The DevOps pipeline leverages Git + Jenkins + NuGet/NPM for CI/CD, with Docker + Kubernetes ensuring elastic deployment and canary releases.

Solution Advantages

The system complies with ICAO safety standards, supports multi-language and multi-currency adaptation, and meets the operational needs of international hub airports. The modular design allows phased construction, enabling smooth transition from single subsystems to full airport integration, reducing one-time investment risks.

Solution Value

Improve passenger throughput efficiency, enhance security capabilities, optimize airport resource utilization, and increase passenger satisfaction and airport commercial revenue.
