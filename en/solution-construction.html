Application Architecture

The system adopts a "Cloud-Edge-End" three-tier architecture: the end layer deploys IoT sensing devices such as personnel positioning, environmental monitoring, and tower crane monitoring; the edge layer performs real-time data processing and local decision-making; the cloud platform provides unified project management, data analytics, and remote supervision, supporting simultaneous management of multiple projects.

The system supports multiple terminals including WeChat mini-program, PC Web, TV dashboard, APP, and H5, meeting the needs of different roles. Project managers can view global data via PC, supervisors can use mobile APP for on-site inspection, and management can monitor project dynamics in real time through the TV dashboard.
