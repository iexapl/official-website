Solution Architecture

Smart Building IBMS Architecture

The Smart Building solution centres on an IBMS integrated building management platform, built on a .NET 8.0 + ASP.NET Core + Furion microservices architecture forming a unified data middle-platform. The device access layer aggregates data from five subsystems (BA, FA, SA, CA, OA) via multi-protocol gateways supporting Modbus RTU/TCP, BACnet and OPC UA; an MQTT Broker collects IoT sensors and edge gateways, RabbitMQ clusters enable cross-subsystem event-driven linkage, and DotNetCore.CAP guarantees distributed transactional consistency for critical linkage commands. Redis Cluster supports millisecond-level device-state caching, and SqlSugar provides heterogeneous multi-database ORM across MySQL, MongoDB and time-series databases. The data layer uses MySQL for structured business data, MongoDB for time-series monitoring and alarm logs. The application layer delivers a unified O&M management interface with Vue 3 + Element Plus, integrating energy analysis, predictive maintenance, tenant space services and digital-twin visualisation; desktop management clients are built on WPF or .NET MAUI. DevOps uses Git + Jenkins + NuGet/NPM for CI/CD, with Docker + Kubernetes enabling hybrid on-premises and cloud-collaborative deployment.
